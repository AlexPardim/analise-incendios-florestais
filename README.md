# Análise de Incêndios Florestais

Este projeto realiza uma análise de dados de incêndios florestais usando um conjunto de dados do Kaggle.

## Bibliotecas Utilizadas

- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## Estrutura do Projeto

- `data`: Contém o conjunto de dados.
- `notebooks`: Contém os notebooks Jupyter para análise exploratória.
- `scripts`: Contém os scripts Python para pré-processamento e análise.

## Estatísticas dos Dados

As estatísticas iniciais dos dados incluem:
- **Número total de registros**
- **Distribuição de incêndios por região**
- **Distribuição de incêndios por mês**
